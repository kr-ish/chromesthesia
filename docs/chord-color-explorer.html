How to read this — and what "color consonance" means here

Each note is a square swatch (its actual plugin color) and a dot on the hue wheel. The wheel's dashed radial marks sit at 29° and 300° — the bounds of the spectral arc. In 271° arc mode, dots never fall in the ~89° gap between them (the non-spectral purples); in 360° wrap mode they do.

"Color consonance" isn't a defined quantity, but you can read the geometry: notes close in hue (small angle) are analogous — low contrast, can look muddy; notes ~180° apart are complementary — maximum contrast; ~120° apart is a balanced "triadic" relationship.

The structural difference: in 360° wrap a semitone is exactly 30° of hue, so each interval maps to a fixed hue angle no matter the root, and the tritone (6 semitones) is an exact 180° complementary pair. In 271° arc a semitone is 22.6°, so intervals are compressed and none land on exact complementary — the tritone is only 136°. Watch the wheel "shapes" change as you toggle.

Assumptions: root C#4 = 277.18 Hz (Sa madhya saptak), MIDI velocity 100 (chroma ≈ 0.167 before gamut mapping). Lightness rises with pitch height, so higher notes are lighter — that brightness difference is identical in both mappings; only hue changes between them. Octave (P8) is the same hue in both modes (pitch-class constancy), differing only in lightness. See docs/science.md Appendix C.
